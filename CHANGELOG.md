# Changelog

## AMAN OS MVP

- Evolved the AMAN Search interface into an AMAN OS command center while preserving the search flow and server-side search protection.
- Added provider-neutral Search and AI gateway boundaries, a Gemini AI chat adapter, and clearly labeled development mocks.
- Added browser-local projects, conversations, messages, tasks, safe file metadata/content storage, activity, and AgentRun records.
- Added deterministic command routing for General, Search, Research, Task, and File agents.
- Added tests for workspace persistence, agent routing, file validation, gateway fallback, and AI SSE handling.
- Updated PWA cache/versioning for the AMAN OS application shell.
